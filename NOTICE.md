# Source and third-party notices

Original Cirven code is published in source form. This snapshot does not declare a repository-wide open-source license. Third-party components and separately licensed components retain their original terms.

- Frontend dependency and upstream notices are under `apps/agent-shell/public/licenses/`.
- Desktop Markdown renderers, graph layout assets, and vendored source adapters have notices or provenance metadata alongside their source.
- The VS Code companion and deliverable-authoring plugin retain the license files in their directories.
- [Development tools and upstream sources](docs/TOOLS.md) lists additional dependencies obtained separately.
