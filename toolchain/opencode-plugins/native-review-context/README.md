# Cirven frozen-page reader

Private plugin for the fixed OpenCode 1.19.0 runtime. It observes actual custom-tool session/message/call context and delegates to the application-owned loopback broker. Model arguments cannot choose another frame, file, URL, owner or native session. Pictures use structured file attachments, never Markdown-as-media.

The plugin creates one bounded ready receipt outside the workspace. It does not run a model, change permissions, capture a new screen or write user files. The fixed MCP child shares its user/process environment: this is not an OS sandbox. Admission, exact parent verification, counters, cancellation and historical source retention belong to the backend.
