# Cirven 前端开发

用于 Cirven 的操作与阅读界面。先遵本项目 AGENTS/SESSION、DESIGN 与 FEATURE_VALUE_GATE；用户最新视觉选择优先。可借鉴 ChatGPT/Claude 的排版，不复制其配色、品牌或功能。页面品牌仅 Cirven，内部 eeas 兼容标识保留。

## 从任务出发

先分清导航、当前任务输入、对象管理与复杂工作区的职责和唯一入口，再决定位置与最短步骤。用户2026-10-19纠正：会话管理属于左侧会话区域；把整个管理页搬进输入弹层仍是职责混淆。整合不能只换容器，不能把添加菜单做成另一个功能大杂烩。

用户2026-10-19补充：最少必要交互与页面干净整洁、重点突出并列验收；不能为了少一次点击把小选项全堆在主界面。复用已有入口和当前任务，低频设置按需展开，日常选择不无故另开管理页面。所有功能用 docs/FEATURE_VALUE_GATE.md 的工作验收记录；截图、会话、JSON等用户例子不是适用范围上限。普通路径的内部JSON即使折叠也不算可读产品表达，必要依据/授权/错误要按业务内容呈现。

先写用户要完成的动作、当前多余操作与信息阻碍。画出阅读路径、主要动作、必要确认和低频详情，统计点击/输入/切页/重复确认。复用已选项目、模型、文件与授权，保留版本冲突/新权限的必要确认；不能为少一步自动重发或覆盖人工修改。

## 结构与字级

布局按使用频率和当前任务决定主次，不固定聊天所在列。日常对话保留充足阅读与输入空间；工作台按需展开，文件打开后能继续在旁沟通。比较布局时核切换、返回和草稿保留，不用新增位置设置代替直接好用的默认布局。

按 DESIGN 的正文/控件/元信息角色统一设置字体、行高和留白。布局用4px刻度，字级/描边/光学尺寸独立；操作标签已清楚就删重复说明，标题只出现一次。设计表达放在品牌字形、开屏/空白页与状态反馈，不向正文加装饰。共享 token 后检查实际计算样式，不靠最后追加 CSS 猜优先级。正文与输入框同轴，保段落节奏；输入默认仅文字、引用摘要与主要工具，批注全文/旧文件恢复/技术依据按需展开。必要错误和版本变化仍可见。按钮用动作名，原始模型 ID、路径、用户内容不擅自改写。

多行编辑区应随容器伸展，检查原生 cols 默认宽度、实际计算尺寸和最窄视口，不能在宽面板里只剩一小块输入区域。

长文件名用独立可收缩文本节点，完整名称可查，移除/关闭按钮 flex-none 且可键盘到达。菜单依实际触发器定位、在视口内翻转与有界滚动。容器变窄时重排/收纳，禁止用全局更小字或强制不换行掩盖问题。选择工具本身不强开大工作台。

## VS Code

保持同一后台 App/会话/文件与配置，正文阅读和 diff 路由延续已有配对契约。Webview 背景、文字、输入、边框、悬停、选中、焦点、错误和禁用色来自 --vscode-*；字体使用宿主变量；默认正文14/24、控件13、辅助12，尊重较大的宿主字体并保组间留白。无需刷新就跟随 light/dark/高对比/自定义主题。Cirven 标志保留，不能把独立 App 的银白色硬塞进编辑器，也不新建另一套 Agent。

## 一批实现与验证

重要交互先做几个真正不同的可操作原型，同任务、同位置、同比例对照，通常以三到四项含当前基线为一轮；比较最短路径、信息与误用，说明取舍，不用换皮凑数。

先批量盘点，再完整实现；一次代表性截图检查、集中修正、一次确认。用真实页面与 API 验草稿、文件关联、未配置/失败/恢复和键盘/IME，不用纯存在检查代替使用。覆盖中英、宽窄、最小高度、长名称和主题切换。

- 观察可见操作与所有 overflow 祖先的有效交集；仅在窗口内不等于没被输入区/父容器遮住。可滚内容需真正滚到最后操作再核。
- 浮标是紧凑连续点按入口，单独设半径/按钮间距；主页面的宽松阅读留白不可套用到它。以固定球心/等角尽量靠近中心，四周屏边时旋转向内；用真实圆形命中与连续鼠标路径核相邻操作，不能因外接矩形交错盲目拉大半径。
- 同组圆形入口共用固定盒尺寸、内边距与字级，禁止内容撑大单项。检查完整标签和图标距圆边的实际净空；包围盒落在外接方框内仍可能越出圆。空间不足优先整组调整尺寸和布局，不缩字补洞；圆弧核共同球心、等角与命中区不重叠。
- 测量稳态前等本元素有限动效完成，保留过程动效；不能把中间帧当永久溢出。
- 弹层初始焦点由组件库生命周期接管；关闭回正确触发器，保原 textarea 与草稿，不和定时器抢焦点。
- 新增 draftSignal 或持久化选项时，同批核渲染器字段白名单、精确类型/合法值、真实 API 保存读取、重启恢复和正常关闭屏障；控件可操作不代表状态可保存。覆盖隐藏但保活的草稿，保存失败要保留原输入，不能清稿或绕过关闭保护。
- 区分不可变正文版本与同版本的回答/来源观测；刷新后保同 DOM、输入、焦点、滚动和图节点状态。确认产生新版本时核精确 basis，异步新输入或跨项目导航不能被迟回执抢走。
- 保存屏障应有界等待真实回执和保存期间新增的字段或滚动状态；冲突、明确失败和未知结果保持原保护，不自动重发。用实际按钮一次点击验证业务只提交一次，并核正常退出保留最新草稿。不能把滚动自动保存误报为业务保存失败。
- 文件树的选中变化不等于打开或重读动作；实测已选文件再次点击及外部保存后的显示。明确重读时按当前 revision/SHA 更新阅读面板，未保存编辑先保留或让用户处理，不能只刷新引用却仍显示旧稿。
- 同一对象关闭重开也可能共享草稿 key；异步清稿或写结果须匹配原 operation 与精确 basis，不能只检查项目或组件仍存活。分开本机持久化、业务请求结果和展示刷新：刷新失败不把成功改成未知，已发送未知的恢复保存失败不丢原 key；用原操作只读查询核结果，不用较新 head 猜原请求已完成。
- 正常、失败与恢复投影共用原项目/会话/操作身份；错误助手只生成短状态时须由调用方继承发起行的身份，不能改为当前作用域。身份保留与权限保留分开，旧 review/授权不能随错误投影继续生效。以带真实作用域的行核同 DOM、未提交回答/选项、焦点和恢复。
- 多版本 DOM 保活时，仅以当前可见对象判断版本、定位输入和执行动作；隐藏旧对象仍存在不代表页面过期，禁止跨版本复用回答 ID。
- 原生浮窗需先核同一实际窗口的 PID、birth、HWND、可见与最小化状态，再操作其 DOM。发送、收起、最小化、切换模式后重新检查；隐藏页面仍更新文本、控件仍有尺寸，不代表用户可操作。初次发送自动收起时，先从浮标重开同一任务，核原 operation/frame 后再补充，不重发初始问题。
- 自动化每步先保存实际返回或异常，再截图和复核身份；截图或观察超时不能抹掉已发生动作，也不能触发重复保存/发送。测试服务异常与产品异常分别归因；释放测试服务放在可靠清理路径，不靠扩大任务预算掩盖测试阻塞。
- 图的全图概览与可读视口分别验收；定位要能读清目标，中文与关系文字实测换行，完整内容可查。等持久视图就绪和非零画布再初始化；重排、缩窗不能默默丢批注。几何断言通过后还需核实际 canvas 像素与截图。
- 已调宽的侧栏再缩窄窗口也要实测；核两侧与中间区的总宽、有效裁剪和末端操作，不能只看每个尺寸的 fresh 页面。
- DOM observer 派生装饰只在值改变时写；用真实目录 baseline→新增/修改/删除→刷新/重启测心跳与CPU，fresh UNCHANGED目录不能代签历史恢复。
- 原生测试助手或操作卡升级后，逐项对照实际生产者的状态、字段、路径和控件属性；源码哈希或去掉字符串后的 AST 相同，不能证明消费接口匹配。未执行的准备错误与产品运行错误分开保存，先修受影响薄层，再验真实动作。
- 输入区增加选句等处理范围后，主发送、Ctrl+Enter、辅助按钮必须走同一动作；选区哈希核对中也有范围，不能当成空选择落回整文件。清除后拒绝离焦编辑器的迟到 select，旧哈希不得回填新引文；实测清除、IME与连续输入。
- 持久讨论/文件身份使用稳定 key，内存 generation/lease只拒绝迟回。未知操作在切回、刷新和重启后仍须可核原 key；408/429等不明确响应不能当作未提交。结构化回执按字段或规范 JSON 核身份，不用对象键顺序判定另一条请求。
- 内部任务指令保原 wire/历史正文，用户显示另以确切操作、讨论、项目及原文 SHA 关联；typed显示身份随原历史索引保存，不能只靠会丢失的旁路缓存。坏展示索引与失败回执同时出现时仍保短占位和闭合详情，普通用户内容不做前缀过滤。
- 测试服务先核实际进程与独立日志，不把早退后的盲等称冷启动。冻结并绑定被测源码/构建；改源码后旧截图仅作首轮检查，不能追签新源。浏览器与实际 Windows/VS Code 验证分开。

本轮具体反例与证据见 [排版经验](references/layout-lessons.md)，处理排版、弹层、主题或异步对象刷新时按需加载。数字门槛须结合真实内容检查，测试通过不代替用户审美认可。
