# eeas-ext-verify

冻结这次接受的源码/输入/验收/组合；从可信路径执行测试，保存命令、退出码、原始日志和制品。
检查实际执行数量、跳过项、异常和版本关联；不要接受 Agent 的自写通过文件。至少重跑当前功能的失败/恢复路径。
所有功能使用 docs/FEATURE_VALUE_GATE.md 的工作验收记录：用户目标到真实结果及继续/恢复，核实际步骤、重复输入/入口、切页必要性、上下文与草稿、可读结果。底层测试、完整工作、视觉与目标平台资格分别判定；受影响链的已知冗余交互或内部载荷暴露不能被接口PASS掩盖。无界面能力核调用和错误交接，不把用户这轮例子当适用范围上限。
分别记录 source/runtime/environment，不把 synthetic-live 推广成内网工程通过。Windows 和 WSL 分开。
有阻塞就标 BLOCKED，有失败就标 FAIL；生成但没运行是 NOT_RUN。报告仅摘要加证据链接。
