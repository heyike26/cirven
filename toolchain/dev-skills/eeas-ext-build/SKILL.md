# eeas-ext-build

读当前 E，定位对应代码和一个契约。先列本切片的可观察验收，再写最少实现与测试；复用现有库，不顺手改架构。
每项功能先查成熟产品/优质开源/官方资料，提出有实质差异的可行方案作交互与显示对照，选定后完整验证美感与顺畅性；同批相关功能可复用已核来源，不逐按钮盲搜。
所有功能遵守docs/FEATURE_VALUE_GATE.md：先还原目的/阻碍和整条工作链，比较可行备选与当前基线、最短路径及信息显隐，再按批次实施；记录真实整链对照和停止条件，不逐项照抄功能要求。
每轮至少有实际功能代码和测试结果。UI 调真实 API；Mock 只替代外部 Agent。没有样例就使用原创短输入，不开发虚构业务系统。
按影响与风险选择异常、失败、刷新/重启等必要验证，复用仍适用证据；新增或重复须由变化、失败或未决事实驱动，不为数量硬加测试。缺外部权限只隔离相应测试，其他实现继续。
通过后提交可复现记录并更新 SESSION/progress；未通过保留失败，转 debug。不要把文件数量作为进度。

前端/VS Code切片按[Cirven前端规则](../cirven-frontend-craft/SKILL.md)组织完整页面与最少操作；重点核对实际计算样式、祖先裁剪、稳态焦点与主题，不以功能存在或截图窗口范围代替交互验收。
