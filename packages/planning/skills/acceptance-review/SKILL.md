# 复核任务链交付与验收覆盖

按来源与用户目标逐节点检查可观察交付物和验收标准，用acceptance_coverage查漏。区分结构验证、模型建议与真实执行证据，不能把任务返回或静态Mock标成功。发现问题只等待受影响分支；修改新修订，不覆盖旧计划或正在运行的输入。

核对当前情境：新建验证需求是否满足；存量修改还要核对相关旧行为、人工内容和接口/数据是否保留；交付核对实际目标安装/使用与资料版本；维护核对原问题、回归范围及必要的恢复。基线未通过、历史失败、本次回归和未运行项分别报告，不能把源码测试替代已部署版或设备验证。

内容结构参考随附 GitHub Spec Kit v1.1.3（MIT），EEAS 共创与来源规则优先。模板只读取，不启动上游 hooks/CLI。
