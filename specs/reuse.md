# 复用与依赖决策

只研究当前实现缺口，单次记录：需求→最多两个候选→最小实测→选择/替换原因。普通依赖无需反复请示；新增云服务、付费能力、账号授权和较大架构变更先说明。

首选复用 Agent SDK 的工具循环、会话和可用原生扩展。[S01] 缺口是事件/权限/取消时先查公开接口；不要默认 Fork，也不要用读屏自动点击替代程序化接口。SDK 不可用可评估 CLI headless[S04]，并记录语义差异；OpenCode 仅在实际阻塞时实现另一适配器。[S08]

网页获取用已有 HTTP/解析工具，文档解析用成熟库；不要自研 PDF/OCR。E02 首批只必须支持 UTF-8 Markdown/TXT，其他格式显式报不支持；新增格式形成独立切片。初期来源检索为按项目/版本过滤的关键词检索，不强制向量库。

新依赖必须有：精确版本、来源、许可证、平台要求、离线可得性、最小测试和移除替代路径。外网可以获取 GitHub 组件，但源码可获得不代表安装时不会继续下载二进制、浏览器或系统运行库。

不要常驻加载十几个角色。单任务 Harness 原生子代理优先；跨任务并行只在隔离、取消和合并门禁稳定后开启。EEAS 不在第一版重复实现完整 Agent Team 产品。
