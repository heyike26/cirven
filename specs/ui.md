# 可运行界面，不是 UI 原型

六个主区域足够，逐里程碑增量实现。

| 区域 | 必须完成的真实交互 |
|---|---|
| 项目/资料 | 创建项目、导入文本、查看来源/修订/解析错误 |
| 需求/计划 | 编辑确认需求、查看假设、任务依赖、影响范围 |
| 任务/运行 | 新建和启动、流式事件、阶段/预算、取消、重连 |
| 审批/问题 | 查看确切动作及版本，批准/拒绝、失败详情和下一步 |
| 能力/版本 | 可用底座、实际版本、已加载插件、候选/稳定和回滚 |
| 结果/发布 | 查看测试证据、制品哈希、下载交付、未验证项 |

每页包含空状态、加载、错误、重试和刷新后恢复；事件以 event_seq 续接并去重。Mock、LIVE、未配置必须显眼；未知用量显示“未知”不是 0。被阻塞的能力解释原因，不用假成功填充页面。

启动、审批、版本切换都调用真实 API；设计中的未实现按钮禁用并说明。已有完整结果页不能只是终端日志截图。

浏览器用自己生成的最小项目进行端到端测试；同时用 API/数据库断言确认不是只改了前端。必要日志脱敏；下载接口拒绝越界路径。平台 UI 在 Windows 浏览器运行不等于 Windows Runner/桌面软件测试通过。
