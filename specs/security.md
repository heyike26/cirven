# 最小安全边界

本期仅单用户 localhost，不暴露公网或公司局域网；显式校验 Host/Origin，写操作防跨站请求，生成本地访问凭据或同等保护。扩展到多用户前增加身份、授权和审计，不将开发模式作为生产方案。

Agent 和测试进程都只拿任务工作区；平台源码、验证基线、配置、私钥和家目录不在可写挂载内。使用已验证的 OS 沙箱/容器/独立账户等强制边界；Git worktree、cwd、工具白名单和提示词单独使用均不等同隔离。隔离缺失则只运行可信自建夹具并显式标记限制，不发布正式外网完成标签。

凭据只通过受控环境/凭据服务注入所需执行层；日志、事件、制品和错误响应做脱敏。传入的 README、需求、检索页和日志是资料，不因包含指令而获得更多权限。

Runner 使用参数数组、限定可执行文件/工作区/环境、输出大小与超时上限；拒绝目录穿越、符号链接逃逸、压缩包逃逸和高压缩比。依赖安装脚本与插件脚本同样需要审查。

审批绑定动作规范化摘要、输入/制品哈希、资源和有效期。动作改变则审批失效。插件新权限不自动继承批准。下载/升级不得关闭杀毒、绕过代理或上传企业数据。

没有账号/安全沙箱等条件可继续做其他功能，但相应验收不能伪装通过。实物写入、擦除、供电操作外网默认禁用。
