# 外网范围与交付对象

## 必做
开发 EEAS 框架：本地 Web/API/持久化、资料与需求版本、任务 DAG、工作区、Agent 适配、Runner、独立验收、有界 Debug、审批/取消/恢复、插件升级、离线导入准备。不得交付纯聊天壳或仅可点击的假界面。

本期默认单操作员、单控制面、本机/WSL2 开发、localhost 服务；执行器先单作业，隔离和恢复通过后再有限并发。Windows Runner 必须独立验证；Web 平台软件不强制第一版包装成桌面 exe。

## 不依赖企业样例
用户已经明确外网没有样例。不再索要内网任务书、协议、源码、密钥、日志或硬件照片。以原创短需求、临时小仓库和确定性故障夹具验证平台功能。不要先构造复杂业务演示或虚拟数据板协议。

夹具只检验链路，不作为真实嵌入式业务数据、任务复杂度或质量基线。正式业务性能留到内网评估。

## 延后且必须有接入点
企业 GLM/SSO/依赖源、真实协议/SDK/驱动、烧录/HIL/仪器、生产运维、新 PCB、业务上位机。统一状态 NOT_CONNECTED/NOT_VALIDATED，不返回假成功。入口见 handoff/INTRANET.md。

## 判定边界
包结构通过 ≠ 平台功能通过 ≠ 真实 Agent 通过 ≠ 内网工程通过。E00—E10 是软件建设任务；缺少真实 Agent 权限只阻塞对应验收，不阻塞界面、数据库、Mock、验证器和离线功能开发。
